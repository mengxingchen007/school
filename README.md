# 拾光校园工具（真实网站版）

这是从可点击原型改写出来的真实网站代码，用到三个免费服务：
- GitHub：存放这些代码
- Supabase：存真实数据 + 账号登录
- Vercel：把网站发布到一个大家都能访问的网址

## 部署步骤（跟着 Claude 的引导一步步来即可）

1. 在 Supabase 建一个新项目，然后打开 `supabase/schema.sql`，把里面全部内容粘贴到 Supabase 的 SQL Editor 里运行一次，会自动建好所有数据表。
2. 在 Supabase 项目的 Settings -> API 里，复制 `Project URL` 和 `anon public` 这两个值（不是 `service_role`）。
3. 把这个项目文件夹上传到 GitHub 上新建的仓库（网页拖拽上传即可，不需要命令行）。
4. 在 Vercel 里 "Import" 这个 GitHub 仓库，在环境变量里填上第 2 步复制的两个值（变量名分别是 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY`），点 Deploy。
5. 部署完成后，Vercel 会给一个网址，网站就正式上线了。

目前已经做好：登录/注册、课表（添加/编辑/删除课程、单双周、每节课时间）、作业考试 DDL（添加/编辑/删除、完成状态、近期待办提醒）、吃饭抽签（个人清单+公共清单、预算/营业状态筛选、抽签动画、历史记录）、分组抽签（管理员管理名单、随机抽人、历史记录）。
